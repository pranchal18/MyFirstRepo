
### Aim
To create a GitHub repository, clone it to the local system, create a README.md file, and perform the initial commit and push using Git.

### Objectives
- Create a new GitHub repository named MyFirstRepo.
- Clone the repository to the local system.
- Create and edit a README.md file.
- Stage and commit the file using Git.
- Push the commit to GitHub and verify the changes.

### Commands Used

```bash
git clone <repository-url>
cd MyFirstRepo
git status
git add README.md
git commit -m "Initial commit"
git push -u origin main
```

### Learning Outcomes
- Understood the basics of Git and GitHub.
- Learned how to clone a remote repository.
- Learned to stage and commit changes.
- Understood how to push local commits to GitHub.
